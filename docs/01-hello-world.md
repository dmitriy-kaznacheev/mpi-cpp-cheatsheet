# 01 — Hello world

## Минимальная программа

```cpp
#include <mpi.h>
#include <iostream>

int main(int argc, char** argv) {
    MPI_Init(&argc, &argv);

    int rank = 0;
    int size = 0;
    MPI_Comm_rank(MPI_COMM_WORLD, &rank);
    MPI_Comm_size(MPI_COMM_WORLD, &size);

    std::cout << "Hello from rank " << rank << " of " << size << "\n";

    MPI_Finalize();
    return 0;
}
```

Рабочий пример: [`examples/01_hello`](../examples/01_hello/).

## Что происходит

1. **`MPI_Init(&argc, &argv)`** — инициализация MPI. Должна быть первой MPI-функцией. Аргументы `argc/argv` нужны, чтобы MPI мог забрать свои опции командной строки.
2. **`MPI_Comm_rank(comm, &rank)`** — номер процесса в коммуникаторе `comm`. Для `MPI_COMM_WORLD` это число от `0` до `size-1`.
3. **`MPI_Comm_size(comm, &size)`** — число процессов в коммуникаторе.
4. **`MPI_Finalize()`** — завершение MPI. Должна быть последней MPI-функцией. После неё нельзя вызывать MPI.

## `MPI_COMM_WORLD`

Коммуникатор по умолчанию — включает **все** процессы, запущенные через `mpirun`. Именно в нём удобно делать первые примеры. Позже (см. `07-communicators.md`) можно создавать подмножества процессов.

## Ранг и размер

- `rank` — «кто я». Уникален в пределах коммуникатора.
- `size` — «сколько нас». Одинаков для всех процессов.

Типичный паттерн: процесс с `rank == 0` (root/master) делает I/O и раздаёт работу, остальные считают.

## Порядок вывода

Порядок строк в stdout **не гарантирован**: процессы пишут независимо, буферизация `std::cout` может перемешивать строки. Если нужен детерминированный вывод — либо соберите строки и выведите с `rank == 0` после `MPI_Barrier`, либо используйте `MPI_Gather` строк.

## Типичные ошибки

| Ошибка | Последствие |
|---|---|
| Забыть `MPI_Finalize()` | Программа может завершиться, но MPI-ресурсы не освобождены; некоторые реализации ругаются |
| Вызвать MPI-функцию до `MPI_Init` | Неопределённое поведение / падение |
| Вызвать MPI-функцию после `MPI_Finalize` | Неопределённое поведение / падение |
| Использовать `MPI_COMM_WORLD` там, где нужен подкоммуникатор | Лишние процессы участвуют в обмене — дедлок или неверный результат |

## Сборка и запуск

```bash
cmake -S . -B build
cmake --build build -j
mpirun -np 4 ./build/bin/hello
```

Ожидаемый вывод (порядок строк произвольный):

```
Hello from rank 0 of 4
Hello from rank 1 of 4
Hello from rank 2 of 4
Hello from rank 3 of 4
```
