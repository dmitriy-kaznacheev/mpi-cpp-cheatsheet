# 02_matvec

Умножение матрицы на вектор `y = A * x` с распределением строк между процессами.
Демонстрирует блокирующие `MPI_Send` / `MPI_Recv` в паттерне master-worker.

## Сборка и запуск

Из корня репозитория:

```bash
cmake -S . -B build
cmake --build build -j
mpirun -np 4 ./build/bin/matvec 400 --verify
```

Первый аргумент — размер `N` (по умолчанию 400). Флаг `--verify` включает
сравнение с последовательным вычислением и печатает `OK` / `FAIL`.

## Ожидаемый вывод с `--verify`

```
OK (max diff = 0)
```

## Что демонстрирует

- Распределение строк матрицы: процесс `rank` получает `N/size` строк
  (первые `N % size` процессов — на одну больше).
- Рассылку вектора `x` всем процессам через `MPI_Send` / `MPI_Recv`.
- Рассылку блоков матрицы от корня.
- Сбор результатов обратно на корень.
- Проверку корректности через `--verify`.

## Замечания

- Это **учебный** пример с point-to-point. В реальном коде рассылка
  вектора делается через `MPI_Bcast`, а сбор — через `MPI_Gather`
  (см. `docs/03-collective.md`).
- Порядок строк в `y` восстанавливается по смещениям, а не по порядку
  прихода сообщений — `MPI_Recv` с конкретным `src` гарантирует, что
  данные от нужного процесса попадут в нужное место.
